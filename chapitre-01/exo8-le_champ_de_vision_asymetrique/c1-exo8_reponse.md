# Champ de vision du Meta Quest 3

Pour le **Meta Quest 3**, les quatre angles du champ de vision de l’œil gauche sont les suivants :

- Gauche : **−54,00°**
- Droite : **40,00°**
- Bas : **−54,27°**
- Haut : **43,98°**

La valeur négative indique simplement que la direction se trouve du côté opposé à l’axe central du regard. Ainsi, l’œil gauche possède un champ horizontal de :

\[
54,00^\circ + 40,00^\circ = 94,00^\circ
\]

et un champ vertical de :

\[
54,27^\circ + 43,98^\circ = 98,25^\circ
\]

**Source :** [HMD Geometry Database — Meta Quest 3, configuration 72 Hz](https://github.com/risa2000/hmdgdb/blob/master/hmd_cfgs/MetaQuest3_Native_R72.md)

Si l’on employait un champ symétrique de même surface, on conserverait la même largeur totale de vision, mais celle-ci serait mal répartie autour de l’œil et l’image correspondrait moins bien à la géométrie réelle du casque.
